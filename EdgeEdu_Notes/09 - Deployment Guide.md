## Step 1: Backend → Render

1. Go to https://render.com → sign in with GitHub
2. **New + → Blueprint** → pick `AI-TimeTable` repo
   - It reads `render.yaml` automatically
   - Or manually: Root Dir `backend`, Build `pip install -r requirements.txt`, Start `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
3. After creation, go to **Environment** → add:
   - `DATABASE_URL` = Supabase pooler URL
     ```
     postgresql+psycopg://postgres.<ref>:<password>@aws-1-ap-northeast-1.pooler.supabase.com:5432/postgres
     ```
   - `SECRET_KEY` = long random string (auto-generated by blueprint)
4. Deploy → copy URL (e.g. `https://timetable-ai-backend.onrender.com`)
5. Test: `GET /api/health` → `{"status": "ok"}`

### `render.yaml`
```yaml
services:
  - type: web
    name: timetable-ai-backend
    runtime: python
    rootDir: backend
    plan: free
    buildCommand: pip install -r requirements.txt
    startCommand: uvicorn app.main:app --host 0.0.0.0 --port $PORT
    envVars:
      - key: PYTHON_VERSION
        value: "3.11.9"
      - key: DATABASE_URL
        sync: false
      - key: SECRET_KEY
        generateValue: true
```

## Step 2: Frontend → Vercel

1. https://vercel.com → **Add New → Project** → import `AI-TimeTable`
2. **Set Root Directory to `frontend`**
3. Add environment variables:
   - `BACKEND_URL` = `https://timetable-ai-backend.onrender.com` (no `/api`)
   - `NEXT_PUBLIC_BACKEND_URL` = `https://timetable-ai-backend.onrender.com/api` (with `/api`)
4. Deploy

> [!IMPORTANT]
> Both `BACKEND_URL` and `NEXT_PUBLIC_BACKEND_URL` are required.
> - `BACKEND_URL` is for Next.js server-side rewrites
> - `NEXT_PUBLIC_BACKEND_URL` is for client-side direct API calls (bypasses Vercel proxy)

## Auto-Redeploy

Push to GitHub → Vercel and Render auto-redeploy from `main` branch. No manual rebuild needed.

## Common Gotchas

| Issue | Cause | Fix |
|-------|-------|-----|
| "Couldn't reach the API" | Vercel env vars wrong/missing, or backend still waking up | Check env vars. Wait ~50s for cold start |
| Generation slow on first try | Render free tier waking up | UI polls background job, it'll finish even through cold start |
| `tenant/user not found` | Supabase project deleted/paused or credentials rotated | Restore project, update `DATABASE_URL` |
| Schema changes | Missing columns | Auto-handled: startup migrations add missing columns |
| Everyone signed out | `SECRET_KEY` changed | Expected: tokens become invalid |

---

## Free Tier Limitations

| Service | Limitation |
|---------|-----------|
| **Render** | Sleeps after ~15 min idle. First request takes ~50s to wake |
| **Vercel** | Serverless function timeout (default 10s, max 60s on free) |
| **Supabase** | Pauses after 1 week inactivity (on free plan) |

## Local Development

No Docker needed:

```bash
# Backend (terminal 1)
cd backend
python -m venv .venv && . .venv/Scripts/activate
pip install -r requirements.txt
python -m uvicorn app.main:app --reload   # :8000

# Frontend (terminal 2)
cd frontend
npm install
npm run dev                                # :3000
```

- Database: local SQLite file (`timetable.db`) — zero setup
- API proxy: Next.js rewrites `/api/*` → `localhost:8000/api/*`
- No env vars needed locally (defaults work)
